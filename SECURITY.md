# Security Policy

This public repository holds documentation and discovery metadata only, not private source code, credentials or customer data.

To report security issues privately, email **soporte@changuito.com.ar** with subject `Security report — Changuito MCP`. Do not open public issues with exploitable details, tokens or personal information.

Authentication happens in the official Changuito authorization flow; never disclose passwords, token values, secret keys or cookies to AI chats or GitHub. Users can revoke authorized integrations from **Mi cuenta → Conexiones de IA**.

Security claims about the live service require testing of the production endpoint.
